# P0 公开发票数据工作台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在没有企业内部数据库的前提下，完成唯一启用的 Voxel51 公开发票样本、发布方原始标注、本地 MinerU 解析、Obsidian 视图、本地 Release 与备份恢复的 20 条可重复闭环；保留通用公开文件读取器供后续扩展，但本期不登记额外原始来源。

**Architecture:** `flowmate-data` 是一个小型 Bun/TypeScript 编排项目。原件、发布方原始标注以及一份结构化结果镜像放在 `D:\paper\Invoice`；`D:\agent-data\data\flowmate-data` 是可写机器记录和结构化处理结果的主存储；Obsidian 仅保存可重建 Markdown，备份放在 `D:\agent-data\backups\flowmate-data`。结构化数据只允许从处理根单向发布到 `D:\paper`，不做双向同步。所有 Paper Knowledge Engine 内部导入集中在 `src/engine-bridge.ts`；共享引擎只提供 MinerU runner、进程监督、结果规整和机器代理读取，MinerU 运行参数由 Flowmate 的 `config/mineru.local.json` 独立维护。

**Tech Stack:** Bun 1.4、TypeScript、Node 文件系统与加密 API、Paper Knowledge Engine 现有 HTTP/MinerU/进程/锁/规范化/manifest/原子替换实现、Obsidian Markdown。

**Spec:** [P0_公开发票数据工作台目标方案_V2.md](../specs/P0_公开发票数据工作台目标方案_V2.md)

**Global Constraints:** 不创建 SQLite、通用爬虫、插件系统、服务端或 npm 包；不把发票写入 FSD/论文数据库；Flowmate 运行时不读取 `paper-knowledge-engine/config/engine.yaml` 的 MinerU 段，也不通过 `--library fsd` 获取 MinerU 配置；MinerU 派生结果不得成为标签；跨数据集相同文件仍保留各自原件；除用户明确要求的 `D:\paper` 结构化镜像外不增加处理数据副本；单任务、下载并发 1、解析并发 1；所有单元测试使用临时目录和本地 HTTP fixture，不读取或改写现有 FSD 数据；共享仓库当前存在无关未提交改动，每次只暂存本任务列出的文件，禁止 `git add .`。

**Command Working Directories:** Git 暂存与提交命令从 `D:\agent-data` 执行；未带 `cd` 的 Bun/CLI 命令从 `D:\agent-data\backend\projects\flowmate-data` 执行；共享引擎测试从 `D:\agent-data\backend\projects\paper-knowledge-engine` 执行。

## 2. 固定接口与数据契约

所有稳定 ID 都使用安全的小写 kebab-case。`sample_id` 取 `sha256(dataset_id + "\n" + revision + "\n" + source_record_id)` 的前 20 个十六进制字符，并加来源前缀，例如 `voxel51-4a11c3...`；SHA-256 只用于身份和校验，不作为原件目录层级。

```ts
export type OriginKind =
  | 'synthetic' | 'official_example' | 'public_redacted'
  | 'public_document' | 'unknown';
export type DocumentKind = 'invoice' | 'receipt' | 'invoice_template' | 'knowledge';
export type LabelKind = 'none' | 'dataset_annotation' | 'human_reviewed';
export type ProcessingStatus =
  | 'selected' | 'downloaded' | 'processed' | 'cataloged' | 'completed' | 'failed';
export type TaskStatus =
  | 'selected' | 'downloaded' | 'processed' | 'cataloged'
  | 'partial' | 'completed' | 'failed';

export interface FlowmatePaths {
  projectRoot: string;
  paperEngineRoot: string;
  originalRoot: string; // D:\paper\Invoice
  dataRoot: string;     // D:\agent-data\data\flowmate-data
  vaultRoot: string;    // D:\obsidian\data\flowmate-data
  backupRoot: string;   // D:\agent-data\backups\flowmate-data
}

export interface FileRef {
  root: 'original' | 'data';
  path: string;
}

export interface SourceConfig {
  schema_version: 1;
  source_id: string;
  dataset_id?: string;
  reader: 'dataset-records' | 'public-files';
  homepage: string;
  record_count?: number;
  annotated_record_count?: number;
  revision: { kind: 'huggingface-api' | 'content-hash'; url: string };
  record_locator?: { index_path: string; file_url_template: string };
  files?: Array<{ id: string; url: string; document_kind: DocumentKind; parse: boolean }>;
  allowed_origins: string[];
  redirect_origins: string[];
  declared_license: string;
  license_evidence: string;
  retention: 'allowed' | 'unknown' | 'denied';
  local_use: 'allowed' | 'unknown' | 'denied';
  redistribution: 'allowed' | 'unknown' | 'denied';
  origin_kind: OriginKind;
  language: string;
  document_kind: DocumentKind;
}

export interface SampleRecord {
  schema_version: 1;
  sample_id: string;
  dataset_id: string;
  dataset_revision: string;
  source_record_id: string;
  origin_kind: OriginKind;
  document_kind: DocumentKind;
  language: string;
  layout_group: string | null;
  original_ref: FileRef;
  original_sha256: string;
  annotation_ref?: FileRef;
  annotation_sha256?: string;
  source_observations: string[];
  label_ref?: FileRef;
  label_sha256?: string;
  label_kind: LabelKind;
  mapping_version?: string;
  derived_ref?: FileRef;
  parser_key?: string;
  parse_attempt_id?: string;
  content_sha256?: string;
  duplicate_of?: string;
  quality_status: 'not_checked' | 'usable' | 'invalid';
  processing_status: ProcessingStatus;
  allowed_uses: Array<'development' | 'regression'>;
  created_at: string;
  updated_at: string;
}
```

`original_ref`、`annotation_ref` 和处理根内的引用保存为 `{ root: 'original' | 'data', path: '安全/相对/路径' }` 的 JSON 对象，不写机器绝对路径。Obsidian 生成器在渲染时解析为本机绝对链接；Release 生成器改写为 Release 内相对路径。`structured/snapshot.json` 记录机器 record、label、parser key、attempt 及镜像文件的 hash；镜像不是第二个可写主记录。100 条扩容和 FATURA/SCID 等第二来源接入属于 P0 完成后的独立计划，本计划只保证模型和目录能按 `dataset_id` 隔离扩展，不提前实现适配器。
